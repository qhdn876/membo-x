Membo X Privacy Policy

App: Membo X　|　Package: com.membo.app
Effective: November 27, 2026　|　Last updated: November 27, 2026
In short: Membo X requests no system permissions, makes no network requests, and collects or uploads no personal information. All study data stays on your device and is deleted when you uninstall the app.

1. Information we collect

None. Membo X is a local-first flashcard tool. The decks, terms, progress and preferences you create are stored in your device's app-private storage and never leave it.

2. System permissions

PermissionRequestedNotes
InternetNoNo INTERNET permission is declared; the app cannot access the network
CameraNoNot used
MicrophoneNoNot used
ContactsNoNot used
LocationNoNot used
StorageNoNo public storage access; only app-private files
Device identifiersNoNo IMEI, MAC address or Android ID is read

The app declares no uses-permission at all, so no permission dialog appears during installation.

3. Storage and deletion

  • All data is kept in the app's private directory on this device and is inaccessible to other apps.
  • There is no account system, no sign-up and no cloud copy.
  • Clearing app data in system settings, or deleting a deck inside the app, removes the corresponding content.
  • Uninstalling the app removes its local data along with it. We neither can nor wish to retain it.

4. Third-party services

Membo X integrates no third-party SDKs, including analytics, crash reporting, advertising, social login or push services. There are no ads, no in-app purchases and no outbound links from inside the app.

5. Children's privacy

The app has no social, streaming, payment or content-distribution features and does not collect information from children. Because it collects no data at all, it is safe for minors to use.

6. Changes to this policy

If a future version adds network features or data collection, we will update this page and state it clearly in the release notes, and ask for your consent before enabling it.
